## Matthias Meyer

I run [StudioMeyer](https://studiomeyer.io) in Palma de Mallorca. Websites and AI systems for companies, six MCP servers I host and keep running, and whatever turns out to be reusable goes open source in [@studiomeyer-io](https://github.com/studiomeyer-io).

You might know [local-memory-mcp](https://github.com/studiomeyer-io/local-memory-mcp), persistent memory for Claude, Cursor and Codex that runs on SQLite and never leaves your machine. Or [darwin-agents](https://github.com/studiomeyer-io/darwin-agents), which A/B tests agent prompts and rewrites the ones that lose. Or [mcp-armor](https://github.com/studiomeyer-io/mcp-armor) and the Rust tooling around it, built on the assumption that an MCP server is software you hand a shell to.

Most of it comes back to memory. An agent that forgets everything between sessions is a demo, not a tool.
